## Запуск CUDA-версии на удалённом сервере

### Подготовка

Перед началом работы убедитесь, что Docker-образ пересобран с установленным `rsync`. Если вы не пересобирали образ, установите `rsync` вручную:

```bash
sudo apt update
sudo apt install rsync
```

### Запуск

Перейдите в директорию `cuda_remote`:

```bash
cd src/tests/05_grav2/cuda_remote
```

Проверьте, что в файле `cuda_remote_build.sh` указаны корректные HOST, PORT и DIR.

Запустите скрипт:

```bash
./cuda_remote_build.sh
```

Скрипт автоматически выполняет следующие действия:

1. Подключается к удалённому серверу и создаёт рабочую директорию.
2. Синхронизирует исходные файлы проекта с сервером.
3. Конфигурирует и собирает CUDA-версию программы `grav2` с помощью CMake.
4. Запускает собранную программу на сервере.
5. Копирует результаты вычислений с сервера в локальную директорию `build/bin/remote_output`.

Параметры подключения, пути к директориям и настройки сборки задаются в начале файла `cuda_remote_build.sh`.

Результаты расчётов будут находится в папке `/app/src/tests/05_grav2/cuda_remote/build/bin/remote_output$ `.

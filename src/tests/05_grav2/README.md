# Задача 05
Гравитационное движение частиц

---

Система состоит из материальных точек, взаимодействующих посредством гравитационных сил.
Каждая частица характеризуется массой, координатами, скоростью и ускорением.
На движение каждой частицы влияют все остальные частицы системы.

Согласно закону всемирного тяготения, сила взаимодействия между двумя частицами $i$ и $j$ определяется выражением:

$$
\mathbf{F}_{ij} =
G\frac{m_i m_j}{r_{ij}^3}
(\mathbf{r}_j-\mathbf{r}_i),
$$
где $r_{ij} = |\mathbf{r}_j-\mathbf{r}_i|$.

Ускорение каждой частицы вычисляется как сумма гравитационных ускорений от всех остальных частиц:

$$
\mathbf{a}_i =
G\sum_{j\ne i}
m_j
\frac{\mathbf{r}_j-\mathbf{r}_i}
{(r_{ij}^2+\varepsilon^2)^{3/2}},
$$
где $\varepsilon$ — параметр сглаживания (softening), предотвращающий численную сингулярность при малых расстояниях между частицами.

---
Для моделирования движения системы необходимо на каждом временном шаге определять новые координаты и скорости частиц. 

Перед началом расчёта определяются начальные ускорения частиц на основе их исходного расположения. Затем на каждом временном шаге выполняются следующие операции:

* Обновление координат. По текущим координатам, скоростям и ускорениям вычисляется новое положение каждой частицы:

$$
\mathbf{r}^{n+1} =
\mathbf{r}^{n}+
\mathbf{v}^{n}\Delta t+
\frac{1}{2}\mathbf{a}^{n}\Delta t^2.
$$

* Пересчёт ускорений. Для нового расположения частиц вычисляются гравитационные ускорения, обусловленные взаимодействием со всеми остальными частицами.

* Обновление скоростей. С использованием ускорений в начале и конце временного интервала вычисляются новые скорости:

$$
\mathbf{v}^{n+1} =
\mathbf{v}^{n}+
\frac{\mathbf{a}^{n}+\mathbf{a}^{n+1}}{2}\Delta t.
$$

## Задание 1. Реализация функции для всех частиц

1. Реализовать цикл для вычисления ускорений в функции `compute_part_accelerations`
    * Вычислите относительные координаты частиц `dx` и `dy`.
    * С учётом параметра `SOFTENING` вычислите расстояние между частицами и его третью степень.
    * Рассчитайте вклад каждой пары частиц во взаимные ускорения.
    * Обновите ускорения обеих частиц, учитывая противоположные направления взаимодействия и массы частиц.
2. Реализовать функцию `all_particles_method`, моделирующую движение системы частиц.
    * Вычислите начальные ускорения всех частиц с помощью compute_part_accelerations.
    * Создайте копию начального состояния системы для хранения параметров на предыдущем шаге.
    * На каждом шаге обновите координаты частиц, используя их предыдущие координаты, скорости и ускорения.
    * Пересчитайте ускорения частиц для новых координат.
    * Обновите скорости, используя среднее значение ускорений на предыдущем и текущем шагах.
    * Сохраняйте состояние системы каждые SAVE_EVERY шагов с помощью save_solution_part.
    * Подготовьте обновлённое состояние системы для следующей итерации.

## Задание 2. Реализация метода всех частиц на GPU

1. Реализовать CUDA-ядро `compute_part_accelerations`.
   * Возьмите за основу реализацию этой функции на CPU.
   * Определите глобальный индекс частицы, за которую отвечает каждая нить. Предусмотрите проверку выхода за границы массива.
   * Инициализируйте ускорения частицы нулевыми значениями.
   * Организуйте перебор всех частиц системы для вычисления гравитационного взаимодействия.
   * Вычислите относительные координаты и расстояние между частицами с учётом `SOFTENING`.
   * Рассчитайте и накопите компоненты гравитационного ускорения `ax` и `ay`.

2. Реализовать CUDA-ядро `compute_coordinates`.
   * Обновите координаты частиц, используя координаты, скорости и ускорения из предыдущего состояния.

3. Реализовать CUDA-ядро `compute_velocity`.
   * Обновите скорости частиц, используя ускорения из предыдущего и текущего состояний.

4. Реализовать функцию `all_particles_method`.
   * Перенесите начальный массив частиц из `std::vector` в `thrust::device_vector`.
   * Получите указатель на данные в памяти GPU и определите количество CUDA-блоков.
   * Запустите `check_kernel` для проверки передачи данных на GPU.
   * Вычислите начальные ускорения частиц с помощью `compute_part_accelerations`.
   * Реализуйте последовательный запуск ядер обновления координат, ускорений и скоростей на каждом шаге моделирования.
   * Организуйте хранение предыдущего состояния частиц в отдельном массиве `bodies_old`. Перед обновлением координат копируйте в него текущее состояние частиц.
   * При сохранении результатов скопируйте данные из памяти GPU в `std::vector` с помощью `cudaMemcpy` и вызовите `save_solution_part`.

Обратите внимание:
* Для хранения данных на GPU используется `thrust::device_vector`.
* При запуске CUDA-ядра необходимо передавать количество блоков и нитей в блоке.
* `bodies_old` хранит состояние частиц до текущего шага моделирования и используется для обновления координат и скоростей.
* `cudaMemcpy` используется для передачи результатов с GPU на CPU перед сохранением.

## Задание 3. Оптимизация вычислений на GPU
1. Добавьте `__restrict__` к указателям в CUDA-ядрах, чтобы сообщить компилятору об отсутствии их взаимного перекрытия.
2. Оптимизировать CUDA-ядро `compute_part_accelerations`.
   - Реализуйте альтернативную версию ядра с использованием разделяемой памяти (`shared memory`). Все нити блока должны корректно проходить точки синхронизации. 
   - При загрузке последнего тайла необходимо проверять границы массива.
   - Разбейте массив частиц на блоки (тайлы) размером `TILE`(Размер `TILE` должен соответствовать количеству нитей в блоке).
   - Организуйте совместную загрузку координат и масс частиц из глобальной памяти в `shared memory` всеми нитями блока.
   - Используйте загруженные данные для вычисления ускорений частиц текущего блока.

   - Предусмотрите обработку последнего неполного тайла.

3. Дополнительно оптимизировать вычисления.

   - Примените `#pragma unroll` для разворачивания внутреннего цикла.
   - Сохраните координаты обрабатываемой частицы в регистрах, чтобы избежать повторного чтения из глобальной памяти.

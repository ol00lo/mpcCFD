# CSR Matrix Multiplication

## Задача

Реализовать умножение двух разреженных матриц, представленных в формате CSR:

```text
C = A * B
```

Размеры матриц:

```text
A: M × N
B: N × K
C: M × K
```

Матрицы гарантированно согласованы для умножения.

---

## CSR

CSR хранит разреженную матрицу с помощью трёх массивов:

```text
vals
col
row
```

Например, матрица:

```text
0  2  0
3  0  4
0  0  5
```

представляется как:

```text
values  = [2, 3, 4, 5]
col_idx = [1, 0, 2, 2]
row_ptr = [0, 1, 3, 4]
```
---

## Что необходимо реализовать

### 1. Последовательное умножение

Реализовать функцию:

```cpp
CSRMatrix multiply(const CSRMatrix& A, const CSRMatrix& B);
```

Алгоритм должен работать непосредственно с CSR-представлением и не должен преобразовывать матрицы в плотный формат.

Для каждой строки `A` необходимо:

1. пройти по ненулевым элементам строки;
2. для каждого `A[i][j]` найти ненулевые элементы строки `B[j]`;
3. выполнить умножение;
4. накопить результат в соответствующем элементе строки `C`.

### 2. Параллельное умножение

Реализовать:

CSRMatrix multiply_parallel(
    const CSRMatrix& A,
    const CSRMatrix& B,
    std::size_t num_threads);

Распараллелить вычисление по строкам матрицы A.

Каждый поток должен обрабатывать свой диапазон строк.s

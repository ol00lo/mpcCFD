# Задача 01
Умножение CSR-матрицы на вектор

## 1. Последовательное умножение

Реализовать умножение CSR-матрицы на вектор:
$$
u = Ax
$$
где `A` - квадратная CSR-матрица, `x` - входной вектор, `u` - результирующий вектор.

## 2. Параллельное умножение

Распараллелить вычисление результата.

* Разделить строки матрицы между потоками блоками.
* Количество потоков должно задаваться пользователем и может быть произвольным.
* Каждый поток должен самостоятельно вычислять элементы результирующего вектора для своего блока строк..

## 3. Потокобезопасный вывод

Добавить вывод результатов каждого потока.

После завершения обработки своего блока поток должен вывести:

* свой `thread_id`;
* вычисленные им элементы результирующего вектора.

Пример:

```text
===================== thread_id = 1
u[8] = ...
u[9] = ...
u[10] = ...
u[11] = ...
```

Вывод разных потоков не должен перемешиваться. Для синхронизации доступа к `std::cout` использовать `std::mutex`.

## 4. Обработка исключений

Добавить проверку индексов столбцов CSR-матрицы.

Если индекс столбца выходит за границы вектора, поток, выполняющий соответствующую строку, должен выбросить исключение.

Требования:

* исключение должно возникать в рабочем потоке;
* рабочий поток должен сохранить исключение с помощью `std::exception_ptr`;
* основной поток должен получить сохранённое исключение после завершения рабочих потоков;
* для повторного выброса использовать `std::rethrow_exception()`;
* в основном потоке вывести сообщение об ошибке.

## 5. Кэширование матриц

Добавить кэш для созданных матриц.

При создании матрицы параметры:

* размер `n`;
* заполненность `fill_portion`;
* `seed`;

должны использоваться как ключ кэша.

Если матрица с такими параметрами уже существует в кэше, повторно генерировать её не нужно.

Доступ к кэшу из нескольких потоков должен быть потокобезопасным.

## 6. Генерация матриц

Функция генерации матрицы должна создавать заданное количество ненулевых элементов.

Например, для:

```text
n = 100
fill_portion = 0.1
```

матрица должна содержать:

```text
100 × 100 × 0.1 = 1000
```

ненулевых элементов.

Одинаковые пары `(row, column)` не должны приводить к уменьшению фактического количества ненулевых элементов.

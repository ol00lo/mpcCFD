# Задача 03
Пересечение прямоугольников

---
Даны N прямоугольников (bounding box), заданных:

- координатами центра (x, y);
- половиной ширины hx;
- половиной высоты hy;
- углом поворота angle.

Необходимо определить, какие пары прямоугольников пересекаются, и построить матрицу пересечений:

overlap[i][j] = 1 если прямоугольники i и j пересекаются, и

overlap[i][j] = 0 в противном случае.

### SAT
Для определения пересечения используется Separating Axis Theorem (SAT) - теорема о разделяющей оси.

Для двух выпуклых фигур, если они не пересекаются, существует такая ось, что проекции обеих фигур на эту ось не пересекаются.
Если хотя бы на одной проверяемой оси проекции прямоугольников имеют разрыв, прямоугольники не пересекаются.

Для двух произвольно повернутых прямоугольников достаточно проверить четыре оси:

- две собственные оси первого прямоугольника;
- две собственные оси второго прямоугольника.

Таким образом, задача сводится к последовательной проверке четырёх направлений для каждой пары прямоугольников.

## Векторная реализация

В тестовом файле уже реализован алгоритм определения пересечений с помощью обычных Python-циклов.

Необходимо реализовать тот же алгоритм без циклов по прямоугольникам, используя векторные операции библиотеки NumPy.

Для решения задачи понадобятся:

- `slice` — выбор нужных столбцов массива;
- `broadcasting` — выполнение операций над массивами разных размеров;
- `einsum` — вычисление скалярных произведений и других операций над многомерными массивами.

### 1. Slice

`slice` позволяет выбрать часть массива.

Например, для реализованных боксов:

```python
boxes[:, :2]
```

выбирает координаты центров всех прямоугольников:

```text
[x, y]
```

а:

```python
boxes[:, 2:4]
```

выбирает размеры:

```text
[hx, hy]
```

Таким образом, вместо обработки каждого прямоугольника отдельно можно сразу получить массивы с нужными данными для всех прямоугольников.

---
### 2. Broadcasting

Broadcasting - механизм NumPy, позволяющий выполнять поэлементные операции над массивами совместимых форм.

Чтобы получить все комбинации элементов двух массивов, можно добавить размерность с помощью `None`:

```python
a[:, None] + b[None, :]
```

Например:

```text
a.shape = (3,)  →  a[:, None].shape = (3, 1)
b.shape = (2,)  →  b[None, :].shape = (1, 2)

в результате (3, 2)
```

NumPy автоматически «растягивает» размерности:

```text
[[a₀+b₀, a₀+b₁],
 [a₁+b₀, a₁+b₁],
 [a₂+b₀, a₂+b₁]]
```

В этой задаче broadcasting используется для выполнения операций сразу для всех пар прямоугольников.

---

### 3. `einsum`

`np.einsum` задаёт операции над измерениями массивов с помощью буквенных индексов.

Основные правила:

* одинаковая буква у нескольких массивов означает, что соответствующие измерения участвуют в одной операции;
* буква, которая есть во входных массивах, но отсутствует после `->`, суммируется;
* буквы после `->` определяют форму результата.

Например:

```text
("ij,jk->ik", A, B)
```

означает:

$$
    C_{ik} = \sum_j A_{ij}B_{jk}
$$


В этой задаче `einsum` используется прежде всего для массового вычисления скалярных произведений без циклов Python.

## Шаги решения

Векторную реализацию удобно разбить на несколько этапов.

### 1. Построить собственные оси всех прямоугольников

Для каждого прямоугольника по его углу `angle` необходимо получить две взаимно перпендикулярные единичные оси:

```text
u = (cos(angle), sin(angle))
v = (-sin(angle), cos(angle))
```

В результате должен получиться массив:

```text
[N, 2, 2]
```

где:

* `N` — номер прямоугольника;
* `2` — ось `u` или `v`;
* `2` — координаты `x` и `y`.

---

### 2. Вычислить взаимные проекции осей

Для каждой пары прямоугольников вычислить скалярные произведения всех пар их осей [N, 2, N, 2]:

```text
ось A × ось B
```

Например:

```text
uA · uB
uA · vB
vA · uB
vA · vB
```

Эти значения нужны далее для вычисления проекций прямоугольников на оси друг друга.

---

### 3. Вычислить радиусы проекций

Для каждой пары прямоугольников необходимо вычислить половину длины проекции каждого прямоугольника на оси второго прямоугольника.

Используется формула:

$$
    r = h_x|u\cdot n| + h_y|v\cdot n|
$$

где `n` — проверяемая ось.

Для всех пар прямоугольников необходимо получить радиусы проекций на оси второго прямоугольника [N, N, 2].

---

### 4. Вычислить векторы между центрами

Для каждой пары прямоугольников:

$$
    d_{ij}=c_j-c_i
$$

где `c_i` и `c_j` — центры прямоугольников.

В результате для каждой пары должен получиться двумерный вектор:

```text
[N, N, 2]
```

---

### 5. Спроецировать расстояния между центрами на оси

Для каждой пары прямоугольников необходимо вычислить:

$$
    |d_{ij}\cdot n|
$$

для обеих осей второго прямоугольника.

Таким образом, для каждой пары получаются абсолютные значения проекции вектора между центрами на две оси второго прямоугольника [N, N, 2].

---

### 6. Проверить условие отсутствия пересечения

Для каждой проверяемой оси сравнивается проекция расстояния между центрами с суммой радиусов проекций двух прямоугольников.

$$
    |d\cdot n| > r_A+r_B
$$

Если оно выполняется, найдена разделяющая ось, поэтому соответствующая пара прямоугольников не пересекается.

Необходимо выполнить проверку для:

* двух осей первого прямоугольника;
* двух осей второго прямоугольника.

Если хотя бы по одной из четырёх осей найдено разделение, пересечения нет.

В результате должна быть получена матрица:

```text
overlap.shape == (N, N)
```

с единицами для пересекающихся пар и нулями для непересекающихся.

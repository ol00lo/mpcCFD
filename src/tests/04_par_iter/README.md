# Задача 04
Параллельные итерационные алгоритмы

---
Рассматривается задача решения системы линейных алгебраических уравнений $Ax=f$. Матрица и вектор правых частей генерируются случайным образом; диагональное преобладание матрицы обеспечивает сходимость рассматриваемых итерационных методов. В качестве начального приближения используется нулевой вектор. Вычисления завершаются при достижении заданной точности по невязке или после максимального числа итераций.

## Задание 1. Метод Якоби с использованием пула потоков

Реализовать функцию `solve_jacobi_pool` на основе `solve_jacobi_parallel`, заменив создание потоков на каждой итерации их повторным использованием.

1. Реализовать пул потоков, который создаёт заданное количество рабочих потоков и позволяет многократно передавать им задачи. Потоки должны завершаться при уничтожении пула.

2. Создавать пул один раз на время решения системы. Распределять строки матрицы между рабочими потоками, учитывая случаи, когда число строк не делится на число потоков или меньше него.

3. На каждой итерации вычислять новые компоненты решения по значениям предыдущего приближения. Для этого хранить старое и новое приближения отдельно.

4. Обеспечить завершение всех задач текущей итерации до перехода к следующей. Для ожидания можно использовать std::condition_variable и счётчик завершённых задач либо другие подходящие механизмы синхронизации.

5. После завершения итерации вычислять невязку и проверять условие остановки. Не допускать гонок данных при работе с векторами приближений и невязкой.

6. Обеспечить корректное завершение пула при выходе из функции, в том числе при досрочном завершении вычислений.

7. Сравнить `solve_jacobi_pool` с `solve_jacobi_serial` и `solve_jacobi_parallel` для $(N=100,\ 1000,\ 5000,\ 10000)$. Проверить время выполнения и итоговую невязку.

## Задание 2. Реализация `solve_async`

Реализовать асинхронный алгоритм решения системы линейных уравнений с использованием нескольких рабочих потоков. Каждый поток самостоятельно выбирает строку матрицы и обновляет соответствующую компоненту решения, используя текущие значения остальных компонент. Потоки работают независимо друг от друга, а основной поток периодически проверяет невязку и определяет момент остановки вычислений.

1. Создать заданное количество рабочих потоков. Каждый поток должен выполнять обновления до получения сигнала остановки. Для хранения общего вектора приближений использовать `std::vector<std::atomic<double>>`, чтобы обеспечить безопасный параллельный доступ к его компонентам.

2. Реализовать четыре стратегии выбора строки в рамках одной функции, изменяя только способ выбора строки.
   - Случайный выбор: выбирать случайную строку при каждом обновлении.
   - Перемешанная последовательность: заранее перемешать индексы строк и последовательно перебирать их, повторяя последовательность после окончания.
   - Общий циклический счётчик: использовать общий атомарный счётчик и выбирать строку по формуле $counter \% N$.
   - Локальные циклические счётчики: каждый поток самостоятельно перебирает строки, начиная с назначенной ему позиции.

3. Реализовать обновление выбранной компоненты по формуле метода Гаусса-Зейделя. При вычислении использовать текущие значения остальных компонент вектора, которые могли быть изменены другими потоками.

4. Организовать проверку сходимости в основном потоке. Периодически считывать компоненты атомарного вектора в обычный вектор `std::vector<double>` и вычислять невязку. Учесть, что частые проверки требуют дополнительного времени, особенно при больших размерностях системы.

5. При достижении заданной точности или максимального числа условных проходов по строкам передать рабочим потокам сигнал остановки и скопировать итоговое приближение в выходной вектор.

6. Проверить каждую стратегию на нескольких размерностях системы. Для каждого запуска зафиксировать время выполнения, итоговую невязку и число обновлений по общему счётчику. 

## Задание 3. Сравнение производительности

1. Сравнить время выполнения `solve_jacobi_serial`, `solve_jacobi_parallel`, `solve_jacobi_pool`, `solve_seidel_serial` и `solve_seidel_async` для нескольких размерностей системы.
2. Для `solve_seidel_async` сравнить все четыре стратегии выбора строки.

## Дополнительное задание*. Метод исключения Гаусса

Реализовать прямой метод Гаусса для решения системы линейных уравнений и сравнить его с реализованными итерационными алгоритмами.

1. Реализовать функцию `solve_gauss`, выполняющую прямое решение системы методом исключения Гаусса. Предусмотреть перестановку строк при необходимости выбора главного элемента, чтобы избежать деления на слишком малые значения.
2. Проверить корректность решения, вычислив невязку. Сравнить полученный результат с результатами итерационных методов.
3. Измерить время выполнения метода Гаусса и сравнить его с `solve_jacobi_serial`, `solve_jacobi_parallel`, `solve_jacobi_pool`, `solve_seidel_serial` и `solve_seidel_async`.

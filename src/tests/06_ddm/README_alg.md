# Задание 6.1

## Алгебраический метод Шварца

Использование алгебраического метода Шварца с перекрытием для решения уравнения Пуассона с условиями Дирихле.

В отличие от многодоменного метода Шварца, обмен данными здесь выполняется после каждой матричной операции в процессе итерационного решения.

Вектор распределяется между MPI-процессами с перекрытием:

Глобальный вектор формируется из локальных:

$$
u=\sum_r\Chi_r u_r,
$$

где $\Chi_r$ - вес локального значения: 0 для ghost-узлов, 0.5 для буферных и 1 для внутренних узлов.

Вектор называется согласованным, если значения в буферной зоне на разных процессах совпадают. Локальные матричные операции могут нарушать эту согласованность, поэтому после них необходимо выполнять обмен и согласование значений.

---

`DistributedVector` хранит локальные части глобального вектора с перекрытием между MPI-процессами. Обеспечивает согласование значений в перекрывающихся областях через взвешенный обмен данными (`MPI_Isend`, `MPI_Irecv`), а также сборку глобального вектора на процессе с рангом 0.

## Задание 1. Распределённый вектор

В тесте `mpi_distributed_test/[distributed-vec]` рассматривается заполнение распределённого вектора, обмен граничными значениями и вычисление суммы элементов и суммы квадратов.

Сейчас сумма вычисляется на одном процессе: сначала собирается глобальный вектор, затем выполняется суммирование.

1. Вычислить локальную сумму элементов с учётом весов $\Chi$.
2. Получить глобальную сумму с помощью `MPI_Allreduce`.
3. Аналогично вычислить сумму квадратов элементов.

При вычислении суммы квадратов учитывайте, что вектор должен быть согласованным. Перед вычислениями вызывается `vec.exchange_bc()`. Квадрат необходимо брать от значения вектора, а вес применять при суммировании.

Проверить результаты сравнением с исходным глобальным вектором.

## Задание 2. Распределённый решатель Зейделя

Реализовать `DistributedSeidelMatrixSolver` в файле `utils/distributed_mat_solver.cpp` по аналогии с `SeidelMatrixSolver` из `cfd/mat/mat_solver.hpp`.

В тесте `mpi_distributed_test/[distributed-mat]` задана трёхдиагональная матрица, решение которой представляет собой линейную функцию.

1. Реализовать итерационный процесс Зейделя для локальной матрицы и распределённой правой части.
2. Обеспечить согласование распределённого вектора после локальных матричных операций.
3. Реализовать проверку сходимости по невязке.
4. Вернуть количество выполненных итераций.

Обратите внимание на вызов:

```cpp
context->invalidate_ghost_slae_rows(csrmat, rhs);
```

Строки матрицы, соответствующие ghost-узлам, не определены корректно. Они не влияют на глобальное решение, поскольку значения ghost-узлов восстанавливаются при обмене. Однако эти строки могут влиять на вычисление невязки.

Поэтому перед решением ghost-строки матрицы и соответствующие элементы правой части обнуляются.

Реализовать решение уравнения Пуассона с помощью распределённого решателя из предыдущего задания в `mpi_algebraic_schwarz_test.cpp/[algebraic-schwarz]`.

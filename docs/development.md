## 1. Сборка проекта
Для сборки проекта используется задача VS Code.

Нажмите
**Terminal → Run Build Task...**
или используйте
**Ctrl+Shift+B**.

По умолчанию выполняется:
```text
CMake: Build Debug
```
Она автоматически:
1. создаёт или обновляет конфигурацию CMake в директории build/;
2. компилирует проект;
3. создаёт исполняемый файл build/bin/multithreading_tests.

Если в коде есть ошибки компиляции, они будут показаны в терминале и в разделе Problems.

---
Для сборки Release откройте **Terminal → Run Task...**
и выберите **CMake: Build Release**.

Release-сборка находится в build-release/bin/multithreading_tests.

## 2. Запуск проекта
Для запуска откройте 
**Run and Debug**
или нажмите
**F5**.

Выберите конфигурацию **Debug tests** или **Release tests**.

После запуска VS Code попросит ввести тег теста. 
Тег теста указан непосредственно в исходном коде в макросе `TEST_CASE`:
```cpp
TEST_CASE("Create and join a thread", "[simple_test]")
```
В данном примере тег - `[simple_test]`.
После этого будет запущен только тест с соответствующим тегом Catch2.

Если хотите запустить все тесты тег можно не писать.

## 3. Отладка проекта
Отладка доступна для конфигурации **Debug tests**.
Выберите её в разделе Run and Debug и нажмите **F5**. Перед запуском будет автоматически выполнена Debug-сборка.

Можно устанавливать обычные точки останова непосредственно в `.cpp` файлах.

## 4. Задачи
Все учебные задания находятся в директории:

```text
tasks/
```
Каждое задание располагается в отдельной директории.

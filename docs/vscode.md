# Работа с VS Code

В проекте VS Code используется не только как редактор кода. Он умеет автоматически:

* собирать проект;
* запускать программу;
* запускать тесты;
* подключаться к отладчику;
* выполнять заранее настроенные команды.

Для этого используются файлы конфигурации в папке `.vscode`.

---

## 1. Папка `.vscode`

В проекте может находиться папка:

```text
.vscode/
├── tasks.json
└── launch.json
```

Эти файлы нужны для настройки команд VS Code.

### `tasks.json`

Файл `tasks.json` описывает **задачи**, которые VS Code может выполнить по команде.

Например:

* собрать проект;
* удалить папку `build`;
* запустить тесты;
* выполнить другую команду.

### `launch.json`

Файл `launch.json` описывает, **как запускать программу через отладчик**.

Он определяет:

* какую программу запускать;
* с какими аргументами;
* где искать отладчик;
* какие дополнительные действия выполнить перед запуском.

---

# 2. Сборка проекта 
Комбинация:

```text
Ctrl + Shift + B
```

запускает **Build Task** — задачу сборки проекта.

В нашем проекте эта команда используется для сборки программы.

Например, VS Code может выполнить:

```bash
cmake --build build
```

То есть происходит примерно следующее:

```text
Ctrl + Shift + B
       ↓
VS Code находит задачу сборки
       ↓
запускает команду сборки
       ↓
CMake компилирует исходный код
       ↓
получается исполняемый файл
```

Если в коде есть ошибка компиляции, сборка завершится с ошибкой, и VS Code покажет её в терминале.

---

# 3. Запуск программы через F5

Клавиша:

```text
F5
```

запускает программу **через отладчик**.

Это отличается от обычного запуска из терминала.

При нажатии `F5` VS Code использует настройки из:

```text
.vscode/launch.json
```

В нашем случае в `launch.json` указано какую программу запустить, а так же возможность указать тэг теста.

---
# 4. Что происходит при нажатии F5
Если для конфигурации запуска указана предварительная задача `preLaunchTask`, сначала выполняется она.
Например:

```text
F5
 ↓
собрать проект
 ↓
запустить программу
 ↓
подключить отладчик
```

Поэтому типичная работа выглядит так:

```text
Изменили код
     ↓
     F5
     ↓
Сборка
     ↓
Запуск программы
     ↓
Отладчик
```

Если сборка завершилась ошибкой, программа запущена не будет.

---

# 5. Типичный рабочий процесс

После открытия проекта в Dev Container:

### Собрать проект

Нажмите:

```text
Ctrl + Shift + B
```

или выберите:

```text
Terminal → Run Build Task
```

### Запустить с отладчиком

Нажмите:

```text
F5
```

### Остановиться в нужном месте

Поставьте breakpoint и снова нажмите:

```text
F5
```

### Если нужно просто проверить тесты

После запуска VS Code попросит ввести тег теста. 
Тег теста указан непосредственно в исходном коде в макросе `TEST_CASE`:
```cpp
TEST_CASE("Create and join a thread", "[simple_test]")
```
В данном примере тег - `[simple_test]`.
После этого будет запущен только тест с соответствующим тегом Catch2.

Если хотите запустить все тесты тег можно не писать.

# Подготовка проекта
## 1. Клонирование репозитория

Откройте терминал или PowerShell и перейдите в директорию, в которой будет находиться проект.

Склонируйте репозиторий:
```bash
git clone https://github.com/ol00lo/mpcCFD.git
```
Перейдите в директорию проекта:
```bash
cd mpcCFD
```
Проверьте, что репозиторий клонирован корректно:
```bash
git status
```
В результате должна отображаться информация о текущей ветке и рабочем дереве проекта.

[Подробнее про работу с git](git.md).

## 2. Сборка Docker-окружения

Запустите Docker Desktop. 

В корневой директории проекта (mpcCFD) выполните:
```bash
docker compose up --build -d
```
Docker прочитает `Dockerfile` и создаст образ с необходимым окружением.

Первичная сборка может занять некоторое время.

[Проверка работы контейнера]((docker.md#9-проверка-работы-контейнера)).

## 3. Работа с Visual Studio Code
Чтобы работать с Docker'ом нужно установить расширение (Extensions) Dev Containers. Для этого нажмите **Ctrl + Shift + X** и введите 
```bash
Dev Containers
```

Откройте корневую директорию проекта в Visual Studio Code. Потом палитру команд **Ctrl + Shift + P** и введите:
```bash
Dev Containers: Attach to Running Container...
```
Выберите контейнер проекта, сервис cpp. 
После подключения VS Code откроет новое окно, работающее внутри контейнера.

После подключения к контейнеру откройте директорию проекта (для этого используйте: 
**File → Open Folder...**
или сочетание клавиш:
**Ctrl + K, Ctrl + O**):
```bash
/app
```

После открытия проекта VS Code предложит установить рекомендуемые расширения.
Согласитесь с установкой.

Если предложение не появилось, откройте раздел Extensions (**Ctrl + Shift + X**) и выберите:
```bash
Recommended → Workspace Recommendations
```
Установите рекомендуемые расширения.

Расширения должны быть установлены в контейнер. В левом нижнем углу VS Code должно отображаться подключение к контейнеру.

[Подробнее про работу с VS Code](vscode.md).

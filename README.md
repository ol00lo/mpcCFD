## Настройка среды
Перед началом работы необходимо установить Docker, Git, VS Code.

- [Установка Linux](docs/install-linux.md)
- [Установка Windows и macOS](docs/install-windows-macos.md)

После установки необходимых инструментов необходимо скачать репозиторий и подготовить Docker-контейнер.

- [Подготовка проекта](docs/setup.md)

Теперь проект можно собирать и запускать непосредственно из Visual Studio Code.

- [Работа с проектом](docs/development.md)
